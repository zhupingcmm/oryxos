- 本 spec 是 US-4「Plugin Tool」的**子能力**。US-4 还包含内建 Tool（FileTools / ShellTools / HttpTools）、MCP 客户端、Sandbox 实现等其他子能力；这些**不在本 spec 范围**内，由 US-4 的总 plan.md 统一覆盖。

- 用户输入引用了外部课件《Notify 模块 原理解析、实现与代码讲解》第 19 节，课件不可直接读取；spec 以 [CLAUDE.md §9.5](../CLAUDE.md) 与宪法 §V 作为权威需求输入。任何与 §9.5 冲突的字段均以 §9.5 为准。
